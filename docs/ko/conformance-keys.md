# 적합성 키

적합성 벡터에 서명한 고정 키페어다. 네 언어 바인딩이 같은 벡터를 돌리려면 같은 키로 서명한 같은 토큰을 읽어야 하므로, 실행할 때마다 만드는 값이 아니라 한 번 정해 두고 쓰는 값이다.

| `kid` | 알고리즘 |
| --- | --- |
| `acps-2026-01` | Ed25519 |
| `acps-2026-02` | RSA-4096 PSS SHA-256 |
| `acps-2027-01` | Ed25519 — 키 교체 시나리오의 새 키 |

각 케이스는 검증에 쓸 공개키를 인라인으로 함께 담는다. 러너는 벡터 파일 외에 아무것도 필요로 하지 않는다.

**이 키로 라이선스를 발급하지 않는다.** 개인키는 SDK 저장소에만 두고, 벡터에 서명하는 것 외에는 쓰지 않는다. 발급용 키페어는 `aclic_generate_keypair`로 만들고 발급 환경 밖으로 내보내지 않는다.
